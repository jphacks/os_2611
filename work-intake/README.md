# Work Intake 0.2

开源工作助手：在现有 Codex／Claude Code 中，根据实际工作材料、外部发现和执行结果，
选择并接入合适能力，完成学习、研究、业务、创作或客户任务。学生、职员、自由职业者
和熟练开发者使用同一机制。无独立模型账号、无常驻服务，Python 3.9+ 标准库即可。

## 开始

完整解压，Mac 双击 **START.command**。已安装的宿主只有一个时自动打开；两个都有时
选择一次。Codex 桌面链接会预填消息，需要点一次发送，这是宿主行为。随后直接说你
在做什么，或给出材料；不必填写画像、编辑配置或学习命令。宿主未安装时会明确提示。

如果已经在 Codex／Claude Code 对话中，直接让它读取本包 AGENTS.md 并开始，别再启动
另一层对话。当前材料、宿主工作目录和已保存任务优先；必要时只补问缺少的材料位置。
安装目录不是工作目录。已有任务会恢复实际工作目录；首次尚未关联时不会把助手源码
误认成用户项目。开发者也可使用 `python3 launch.py --workdir /actual/work`。

## 这版实际增加了什么

- work.py：真实文件读取、公开 HTTPS 获取、原子写入、命令执行和产出核对。
- workstate.py：SQLite 任务与事件记录；任务切换、恢复、纠正、暂停、忘记。
- worktools.py：实际 I/O、文件哈希、进程退出码和 CSV/文本断言。
- 对资料变化、中断操作、重复执行、旧验证结果有程序检查。
- 保存判断检查点，回退判断时不恢复旧权限、不重复执行历史操作。
- 同一任务的具体操作授权会复用；个人画像是可选项，不再阻塞工作。
- 宿主报告与本地独立检查明确区分；传入 JSON 不会变成“连接已验证”。

宿主模型决定下一步，程序负责实际执行、状态和证据。没有硬编码“对内结束才对外”
的流程，也没有把不同身份分成三套程序。深度由实际工作需求决定。

## 能力边界

本地引擎不是大模型，也不是沙箱。命令继承宿主的操作系统权限；只运行已检查且获授权
的命令。外网发现使用宿主真实搜索能力；公开 URL 可使用内置 fetch，但网络限制可能
阻止访问。Binary PDF/XLSX/DOCX 等使用宿主已有文档工具，不预装大依赖。

记忆、连接和调度取决于当前宿主。没有真实调度就不会宣称自动周报已启用。单次生成
周报可独立完成。Claude 共享代码和入口已检查，真实 Claude 模型内交互尚未验证。
Codex 新会话首次打开、安装后的新人体验需与当前宿主内执行验证分开看。

## 数据与卸载

任务进度在 `.private/work.sqlite3`；旧个人画像仍在 `.private/state.json`，仅在此前
用户选择保留时存在。运行目录与文件设为 0700/0600，但不加密。只保留必要工作摘要、
引用和执行日志；命令输出可能含工作资料，不进入分发包或 Git。

“忘记这个任务”删除对应任务记录，不删除用户材料，也无法删除宿主聊天与系统备份。
卸载本助手只需删除解压目录；外部能力的安装和修改应按各自变更记录撤回。没有全局
配置或后台服务被默认安装。实际已生成的工作成果保留在用户工作目录。

## 验证与开发

`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -q`

`python3 build_release.py` 生成轻量运行包与源码包，排除个人状态和开发运行数据。
运行时协议见 docs/runtime.md；真实任务验证及尚未验证部分见 docs/validation.md。
公开架构参考与取舍见 docs/architecture.md。旧 research/ 与 examples/ 是历史案例，
不能当成当前外部事实或真实宿主观测。

本项目不采集员工使用历史，不建设公司监控后台，不要求用户长期依赖本项目。
通过真实任务判断耗时、人工修改、遗漏等是否改善；不编造生产力收益数据。
