# 临时展览空间路线理解：研究备忘录

**材料性质：合成验收材料，不是真实田野研究记录。**

来源仅为本目录的 [reading-notes.md](reading-notes.md)。以下“观察事实”指该合成笔记明确记载的内容，不代表独立核实的现实事件。未引入外部文献。

研究问题：临时展览怎样让第一次到场的人理解空间路线？

## 一、观察事实（笔记明确记载）

| 编号 | 材料中的观察 | 材料未说明的内容 |
| --- | --- | --- |
| F1 | 入口没有地图；三位首次来访者都先询问工作人员。 | 询问的具体内容，以及是否还有其他首次来访者。 |
| F2 | 墙上说明文字较长；两位来访者只看了作品标题。 | 两位来访者是否属于 F1 的三人、停留时间、未读正文的原因，以及说明文字是否涉及路线。 |
| F3 | 地面箭头指向出口，但交叉路口缺少连续标记。 | 来访者是否注意到箭头、是否在该处犹豫或走错，以及出口箭头是否承担参观路线引导功能。 |

## 二、暂时解释（待后续观察核对）

- **入口信息可能不足。** F1 提示可以检查入口是否提供了足够的路线信息；但询问也可能涉及票务、展览内容等。尚不能认定缺少地图导致询问。
- **说明文字可能难以快速浏览。** F2 提示可以检查正文长度、版式和可见性是否影响阅读；也可能与兴趣、时间或其他因素有关。笔记没有证明文字长度造成只读标题，更没有证明它妨碍路线理解。
- **交叉路口的路线提示可能不够连续。** F3 提示可以检查转向处的提示是否衔接；但尚无来访者行为记录证明这一点造成迷路，也不能把出口指引直接等同于完整参观路线。

以上只是解释线索，不是因果结论。三位与两位来访者的记录范围及重合关系不明，不能合并为五人，不能计算总体比例、宣称统计显著或推广到所有首次来访者。

## 三、三个可执行的后续观察问题

以下为后续观察方案建议，尚未实施；如继续使用合成材料，应将新增记录同样标明为合成。

1. **首次来访者在入口询问什么，询问前看过哪些信息？** 在下一次观察时段，对每位经简短确认的首次来访者逐例记录：先看的信息位置、是否询问工作人员、问题是否涉及路线、获得回答后的第一步去向。观察结束后可简短核对其询问原因，区分直接看到的行为与来访者自述。用这些记录核对 F1 的路线信息不足解释，不预设询问都与地图有关。

2. **来访者只读标题时，正文的哪些条件或阅读目的可能有关？** 在同一块墙文前逐例记录可见的停留、靠近和阅读行为，并记录正文位置、字号、照明及是否含路线信息；离开后自愿简短核对其读了哪些部分、为何略过正文。将可见行为与自述分栏，不仅凭视线判断是否读懂，用这些记录核对 F2 的解释及其与路线理解的关联。

3. **来访者在缺少连续标记的交叉路口如何选路？** 选择笔记所指交叉路口，先记录各方向可见的箭头与标记位置，再逐例记录来访者的来向、停顿、回头、询问和所选方向；离开路口后自愿询问其原本目的地。按目的地判断是否需要帮助，避免把任何转向都标为走错，用这些记录核对 F3 的提示连续性解释。

## 四、证据边界与记录要求

后续记录应注明时间、位置及匿名个案编号，并分别保存可观察行为、当事人自述和研究者解释。当前材料没有采集时段、招募方式或代表性依据，适合形成待核对问题，不足以评价整个展览的引导效果。这里没有新增观察结果、真实参与者或文献依据。
